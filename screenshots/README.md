# Application Screenshots

## Smart Gait Dashboard
The dashboard visualizes real-time plantar pressure distribution for both left and right feet using smart insole sensing technology. Pressure points are dynamically represented to monitor gait balance, toe pressure, and heel pressure.

Features shown:
- Left and right foot pressure visualization
- BLE connectivity indicators
- Real-time plantar pressure monitoring
- Baseline calibration support
- Session PDF export functionality
- Clinical dark-themed UI design

## Clinical Analysis Interface
The clinical analysis module evaluates gait symmetry, rehabilitation progress, fall-risk indicators, and lower-limb abnormalities using sensor-driven biomechanical analysis.

Clinical insights displayed:
- Post-stroke hemiplegic gait analysis
- Lower-limb discrepancy detection
- Rehabilitation progress monitoring
- Fall-risk screening
- Clinical status indicators
- Rule-based gait assessment
